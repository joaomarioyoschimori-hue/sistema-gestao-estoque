# Sistema de Gestão de Estoque

Aplicação desenvolvida em Python para gerenciamento de produtos, fornecedores e movimentações de estoque.

## Objetivo

Desenvolver uma solução para facilitar o controle de mercadorias e auxiliar na gestão de pequenas empresas.

## Tecnologias

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Git
